ПЕРЕВІРКА ПОПЕРЕДНЬОГО УРОКУ: ПИТАННЯ Й КЛЮЧІ ДЛЯ АВТОРА
1. [знайомство] Помахати й сказати Hello! Дати час на відповідь.
   Показати: Hello! + малюнок долоні.
   Очікувана відповідь для вчителя: Будь-яке привітання словом або жестом; без оцінки.
2. [інтерес] Українською запропонувати вибрати цікавішу пригоду.
   Показати: Дві картинки: тварина й машинка.
   Очікувана відповідь для вчителя: Власний вибір дитини; правильного варіанта немає.
3. [рух] Провести пальцем коло в повітрі й запросити повторити.
   Показати: Велике коло без букв.
   Очікувана відповідь для вчителя: Будь-яка спроба руху, без оцінювання письма.
4. [слух] Плеснути двічі, потім один раз; запропонувати повторити.
   Показати: Дві долоні.
   Очікувана відповідь для вчителя: Спроба відтворити ритм; це спостереження, не мовний бал.
5. [онлайн] Запропонувати показати картинку на екрані; перевірити, чи вчитель бачить вибір.
   Показати: Малюнок книги.
   Очікувана відповідь для вчителя: Знайдений зручний спосіб показувати.
Слайди 2–4 не містять очікуваних відповідей, підказок під картинками
або змісту нової літери. Схеми виправлення — тільки для вчителя.
