ПЕРЕВІРКА ПОПЕРЕДНЬОГО УРОКУ: ПИТАННЯ Й КЛЮЧІ ДЛЯ АВТОРА
1. [попередній] Показати C; попросити знайти відповідну малу літеру серед b, a, c.
   Показати: C + варіанти b / a / c без малюнків-підказок.
   Очікувана відповідь для вчителя: c
2. [попередній] Показати Cc; попросити звук, не назву літери.
   Показати: Cc без IPA і слів.
   Очікувана відповідь для вчителя: /k/
3. [попередній] Сказати cat без жесту-підказки; попросити показати.
   Показати: Картинки cat / car / apple без підписів.
   Очікувана відповідь для вчителя: Картинка cat.
4. [віддалене] Повернути літеру з уроку 02; запитати її цільовий звук.
   Показати: Aa без IPA.
   Очікувана відповідь для вчителя: /æ/
5. [віддалене] Показати ant з уроку 02; дати до 5–7 секунд назвати.
   Показати: Малюнок ant без підпису.
   Очікувана відповідь для вчителя: ant
